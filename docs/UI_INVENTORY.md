## 1. 앱과 띄우는 법

| 앱           | 기술                                       | 역할                                   | 띄우는 법                                                                                                                            |
| ------------ | ------------------------------------------ | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| SIW Research | Electron + React 19(같은 웹 빌드)          | 차트·연구·백테스트·복기·스크리닝       | 웹: `.claude/launch.json`의 `api`(8765, `SIW_DATA_DIR=data/browser-preview`) + `web`(5173). 설치본: `/Applications/SIW Research.app` |
| SIW Agent    | Tauri 2 + React 19(같은 소스의 agent 빌드) | 승인된 전략 실행(모의투자·실계좌 승인) | `pnpm --filter @siw/desktop exec vite --mode agent`(웹으로 화면만), 설치본: `/Applications/SIW Agent.app`                            |

- 시장 데이터 기본값은 **합성 데이터**(`SYNTH`)다. 실제 시세는 `SIW_MARKET_DATA_PROVIDER=alpaca`와 등록된 키가 있어야 한다. 디자인 검토는 합성 데이터와 빈 저장소(`data/browser-preview`)로 충분하다.
- 화면 언어는 한국어·영어 두 가지다(상태 줄에서 고름). 기본 대상은 한국어다.
- 기술 제약: React 19, 직접 쓴 CSS 한 파일(`apps/desktop/src/styles.css`, 약 4,800줄), 차트는 `lightweight-charts` 5.2.1, UI 라이브러리는 쓰지 않는다. 데스크톱 전용이다(최소 창 960×640). 어두운 테마 하나뿐이다.
- 디자인 시스템 **Deck**: `styles.css` 맨 위 `:root`의 `--siw-*` 토큰(옛 `--term-*`는 별칭으로 남김). 차트 캔버스처럼 CSS 변수를 못 읽는 곳은 `theme.ts`의 `DECK`·`LEDGER_COLORS`·`CHART_CHROME` 값을 쓴다. 두 곳의 값은 같아야 한다.

### 2.1 상단 도구줄

| 요소              | 동작                                                                       |
| ----------------- | -------------------------------------------------------------------------- |
| 종목 검색         | 팝오버. 차트에서 글자를 치거나 Ctrl/⌘+K로도 열림                           |
| 봉 단위           | 즐겨찾기 버튼 + ▾ 메뉴(프리셋·직접 입력·1D·1W)                             |
| 캔들 / 보조지표   | 보조지표 → 보조지표 대화상자(3장)                                          |
| 차트 배치         | 1개·2개·4개                                                                |
| 리플레이          | 켜면 캔들 클릭으로 시작, 재생 도구가 나타남                                |
| 되돌리기          | 템플릿 적용 되돌리기(20단계)                                               |
| 워크스페이스 메뉴 | 저장·다른 이름·이름 바꾸기·삭제, 레이아웃 템플릿, 초기화, 시간 범위 동기화 |

### 2.2 그리기 도구 막대

십자선, 추세선, 수평선, 피보나치 되돌림, 추세 기반 피보나치 확장, 텍스트 메모, 측정, 확대, 자석, 로그 눈금, 전체 보기, 그림 지우기(휴지통). 피보나치를 선택하면 설정 패널이 차트 위에 뜬다.

### 2.3 종목 띠와 차트 하나의 구성

- **종목 띠**(차트 위, `SymbolBand.tsx`): 활성 차트의 종목·거래소·봉 단위·날짜, 그날의 시가·고가·저가·거래량(정규장). 관심종목이 열려 있으면 그 값을 같이 쓴다. 리플레이 중에는 숫자를 숨긴다.
- 십자선 범례(OHLC·변화·거래량·미확정), 지표 범례(지표마다 ⚙ 설정·숨김·삭제·↑vN).
- 데이터 정보 줄(출처·품질·Coverage·결측·조기 폐장·공시 분할 판독).
- 하단 도구줄: 일봉이면 "프리마켓" 토글, 백테스트 결과가 있으면 BT 표시 칩.
- "◀ 이전 봉" 버튼(스페이스 키도 같음).
- 캔들 클릭 → 그 캔들의 기록 목록, 수동(실제)·가상 기록 입력(`TradeEntry`), "Agent에게 묻기"(차트 AI 해설 패널로 감).
- 차트 아래: Pine 전략 결과 보고서(`PineStrategyReport`)가 붙을 수 있다.

## 4. SIW Agent 화면

- 탭 두 개: **모의투자**, **실계좌**(`agent-tabs`).
- 모의투자 탭: 모의투자 띠, 상태 요약 카드 4개(킬 스위치·실행기 마지막 응답·승인한 계획·오늘 의도/체결), 실행기 상태와 LaunchAgent(또는 systemd) 설치·중지·제거, 실행 계획 승인 마법사(전략·계좌 → 종목 → 한도 → 확인), 승인 목록, 보유와 보호 상태, 주문 의도·체결 표.
- 실계좌 탭: 실계좌 띠, 주문 확인 대기(주문마다 승인 버튼, 60초 만료), 실행 계획 승인 목록과 실행기 제어(모의투자 탭과 비슷한 구성).
- 안전 관련 표시(킬 스위치, 모의/실계좌 구분 띠, 승인 버튼)는 **기능상 바꾸면 안 되는 요소**다. 배치·모양은 바꿀 수 있지만, 눈에 띄는 정도와 구분을 약하게 만들면 안 된다.

## 6. 바꾸면 안 되는 것(기능·데이터 규칙)

- 실제 체결 / 수동 체결 / 가상 시나리오 / 백테스트 체결을 **서로 다른 원장으로 구분해 보이는 것**(색·마커·표시 문구).
- 확정/미확정 봉, 사후 정보, 추론(INFERENCE)과 근거의 구분 표시.
- 리플레이 중 미래 데이터를 숨기는 동작.
- 모의/실계좌 구분, 킬 스위치, 주문 승인 버튼(SIW Agent).
- LLM 호출은 사용자가 누를 때만 나가고, 보낼 내용을 볼 수 있어야 한다(비용·개인정보). 대부분 화면에서 "보낼 내용 보기"는 펼쳐 보는 칸이고, 확인 단계를 강제하지는 않는다.
- 금액·수량 표기의 정밀도(소수점 자릿수 규칙).
