# ADR 0054 — 종목 선정에서 SIW Agent 시나리오까지

- **Status:** proposed(초안). 2026-11-09 사용자 정의를 옮겼다. 아래 "사용자가 정할 것"이 정해지기 전에는 새 단계를 구현하지 않는다.
- **Date:** 2026-11-09
- **Related:** [ADR 0051](0051-kiwoom-realtime-condition-watch.md)(조건검색 실시간 기록), [ADR 0052](0052-daily-candidate-screening.md)(당일 후보 스크리닝 A·B·C·D), [ADR 0053](0053-off-exchange-price-structure-model.md)(장외 체결 가격 구조), [ADR 0036](0036-desktop-app-roles.md)(Research·Agent 역할), [ADR 0047](0047-live-orders-per-order-confirmation.md)(실계좌 주문마다 승인)

## Context

2026-11-09 사용자 정의:

- 목적은 **매수·매도할 종목을 선정**하는 것이다. 보유 기간은 1거래일 이내일 수도, n거래일일 수도 있다.
- 종목을 선정한 뒤, **선정된 종목에 한해서** 매수·매도 전략을 논의한다. 순서는 `종목 선정 > 매수·매도 전략 생성 > SIW Agent 시나리오 생성`이다.
- SIW Research와 SIW Agent가 모두 관여한다. 주된 상호작용은 SIW Research에서 일어난다.

이 ADR은 그 흐름 전체를 묶는다. ADR 0052는 이 흐름의 1단계(선정)이고, ADR 0053은 2단계의 스트레스 모델 하나다.

## Decision (초안)

### 1단계 — 종목 선정

사용자 정의: `검색식을 통한 모멘텀 스크리닝 → 해당 주식들에 대한 다크풀/short/뉴스/긴 시계열 차트 분석`.

| 순서 | 내용                   | 이 저장소의 현재 상태                                                                                                                            |
| ---- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1-1  | 검색식 모멘텀 스크리닝 | 있음. 키움 조건검색 실시간 기록(ADR 0051), '오늘의 후보'(ADR 0052 S1), 하루 내 모멘텀 수집(U0, [ADR 0055](0055-intraday-momentum-candidates.md)) |
| 1-2  | 다크풀                 | 있음. 장외 체결 가격대(ADR 0052 D). 5거래일까지만 읽음. 10~21거래일 확장은 결정 대기                                                             |
| 1-3  | 공매도(short)          | 없음. 유료 API를 쓴다(아래 §3)                                                                                                                   |
| 1-4  | 뉴스                   | 있음. news-analysis 서비스의 B 검사. NIR LLM 단계는 모델·비용 상한 확정(2026-11-10), 구현 중. 선정에 필수 아님                                   |
| 1-5  | 긴 시계열 차트         | 있음. 진입조건 검사(ADR 0052 A, 저장한 규칙 전략을 확정 일봉으로)                                                                                |

- **시간:** 선정은 장중에도 계속한다. 주로 미국 장 시간 기준 **정오 이전에 완료**된다. 이것은 선정이 끝나는 시각일 뿐이며, 정오 이후에 진입한다는 뜻이 아니다. 진입 시각은 전략이 정한다.
- 결과는 사용자가 고른 **선정 종목 목록**이다. 화면은 지금의 '오늘의 후보' 패널을 쓴다.

### 2단계 — 선정 종목의 매수·매도 전략

사용자 정의: `각 주식의 movement를 예상 분류 → 분류된 주식들에 대한 실시간 수급 내역 확인 → dilution/darkpool stress model 분석 → 매수·매도 전략 적용`.

| 순서 | 내용                      | 이 저장소의 현재 상태                                                                       |
| ---- | ------------------------- | ------------------------------------------------------------------------------------------- |
| 2-1  | 움직임 예상 분류          | 없음(§1)                                                                                    |
| 2-2  | 실시간 수급 확인          | 없음(§2)                                                                                    |
| 2-3  | 희석·다크풀 스트레스 모델 | 다크풀 쪽은 있음(ADR 0053, 승인 전 단계 `UNKNOWN`). 희석 쪽은 없음(설계안 아래 "참고 문서") |
| 2-4  | 매수·매도 전략 적용       | 규칙 전략과 백테스트는 있음. 분류·수급·스트레스 결과를 전략으로 잇는 부분은 없음            |

### 3단계 — SIW Agent로 넘기기와 검토

- **넘기는 것:** 종목, 전략 버전, 진입·청산 가격대. 사용자 결정이다.
- **넘기지 않는 것:** 근거와 그 밖의 정보는 SIW Research가 가진다.
- **검토:** 넘긴 내용은 SIW Research에서 **외부 감사 LLM과 사용자가 함께** 검토한다. 주문과 승인은 지금처럼 SIW Agent에서 사용자가 한다(ADR 0036·0047). 이 흐름의 어느 단계도 주문을 내지 않는다.

### §1. 움직임 예상 분류

사용자 정의: 움직임은 **주식 수, 긴 시계열 차트 모양, 재료의 성격**에 따라 분류된다. 예시는 다음과 같다.

| 주식 수                 | 예상 움직임                       |
| ----------------------- | --------------------------------- |
| 2백만 주 이내(초저유동) | 피보나치 76.4%까지 닿는 큰 되돌림 |
| 1천만 주 이내           | 피보나치 61.8%까지 닿는 되돌림    |
| 그 이상                 | VWAP 근방의 추세 움직임           |

- 이 체계는 사용자의 관찰에 근거하므로 **불확실성을 전제로 한다. LLM 사용이 필수다**(사용자 결정).
- LLM이 들어가므로, 정하기 전에 "Local AI Gateway 개발·유지보수" 세션에 `[요청 #모델배정]`으로 경로·모델·대체를 상담하고 그 회신을 이 ADR에 적은 뒤 사용자 확정을 받는다(AGENTS.md).
- 분류 결과는 근거(주식 수와 그 출처·시점, 차트 모양 판단에 쓴 봉, 재료 카드)와 LLM의 추론을 나눠 저장한다. 모델·프롬프트 버전과 불확실성을 남긴다.
- **주식 수는 유통주식 수(float)이고, 출처는 주식 희석 분석기다**(2026-11-09 사용자 결정). 기준 시점을 함께 남긴다.
- **각 요건은 가중치 성격이다**(사용자 결정). 주식 수 구간이 분류를 정하지 않는다. 차트 모양이나 재료에 따라 분류가 바뀔 수 있다. 주식 수 구간 계산은 코드로, 세 요건을 합친 판단은 LLM으로 한다. 구간 값과 비율은 사용자 규칙이라 그대로 쓴다.
- **피보나치 되돌림을 확인하는 방법은 복잡해서 별도 논의로 정한다**(사용자 결정).

### §2. 실시간 수급

- 기본 전제는 **일정 거래대금 이상의 거래량 발생**이다.
- 참고 자료: Alpaca 실시간 체결·호가, 키움 실시간 조건검색, 증권사별 매수·매도 호가 자료.
- "수급"은 아직 확실히 정의되지 않았다. **쓸 수 있는 자료에 따라 정의한다**(사용자 결정). 자료별로 받을 수 있는 항목과 권한을 먼저 확인하고, 그 결과를 보고 정의를 정한다.

### §3. 공매도 자료

- **유료 API를 쓴다**(사용자 결정). 결제·구독은 사용자 승인 없이 하지 않는다.
- 공급업체 후보를 비교한 뒤 사용자가 고른다. 비교 항목은 일별 공매도 거래량, 공매도 잔고, 대차 가능 수량, 차입 수수료, 갱신 주기, 과거 자료, 약관(저장·재배포)이다.

## 구현 단위 (각 단계는 사용자 승인 뒤)

0. **U0 하루 내 모멘텀 종목 수집(먼저 시작, 2026-11-09 사용자 결정):** 키움 실시간 조건검색으로 하루 안에 모멘텀이 생긴 종목을 모은다. ADR 0051 기록기(`watch-condition`)와 '오늘의 후보'(ADR 0052 S1) 위에서 한다. → 구현: [ADR 0055](0055-intraday-momentum-candidates.md)(2026-11-09).

1. **U1 공매도:** 유료 공급업체 비교 → 사용자 선택 → 1단계 검사로 추가.
2. **U2 움직임 분류:** 모델 배정 → 주식 수 구간 계산(코드) + 차트·재료 판단(LLM) → 분류 카드.
3. **U3 실시간 수급:** 자료별 항목·권한 확인 → 수급 정의 → 분류된 종목만 장중 감시.
4. **U4 희석 스트레스 모델:** 설계안을 받아 ADR 0053처럼 이식(주식 희석 분석기 세션과 협업).
5. **U5 전략 연결:** 분류·수급·스트레스 결과를 받아 규칙 전략의 진입·청산 가격대를 만든다.
6. **U6 Agent 넘기기와 검토:** 종목·전략 버전·진입·청산 가격대를 SIW Agent 시나리오로 넘기고, Research에서 외부 감사 LLM과 사용자가 검토한다.

## 사용자 결정 (2026-11-09)

- 주식 수: 유통주식 수, 출처는 주식 희석 분석기.
- 피보나치 되돌림 확인: 별도 논의.
- 분류: 차트 모양·재료에 따라 바뀔 수 있다. 주식 수 등 각 요건은 가중치 성격.
- 외부 감사 LLM: Codex.
- 순서: U0(키움 실시간 조건검색으로 하루 내 모멘텀 종목 수집)부터.
- 세션: "종목 선정" 상위 세션을 새로 열고, 그 아래 검색식 하위 세션을 새로 연다. 이 흐름의 구현 단위를 맡은 기존 세션(뉴스, 장외 체결, 스트레스 모델)은 해당 구현 단계에 이르면 "종목 선정" 아래로 옮긴다.

## 사용자 결정 (2026-11-10)

- U0 다음 단계: 1-4 뉴스의 LLM 단계(개별 뉴스 분석 NIR). 구현은 news-analysis 서비스에서 한다.
- **뉴스는 반드시 있어야 하는 것이 아니다.** 기사가 없거나 서비스·LLM이 돌지 않아도 후보를 탈락시키거나 실패로 보이지 않는다.
- NIR 모델: 스크립트 + `openai/gpt-6-luna`(주), `anthropic/claude-haiku-5.5`(대체). Local AI Gateway `[회신 #news-1]` 평가 근거, news-analysis ADR 0002.
- NIR 비용 상한: 기사 1건당 $0.01, 월 $15. 월 상한에 닿으면 LLM을 멈추고 규칙 결과만 낸다.

## 사용자가 정할 것

- 피보나치 되돌림을 재는 방법(별도 논의).
- U1~U6의 순서(U0 다음).
- 실시간 수급의 정의(자료 확인 뒤).

## Alternatives

- **분류를 규칙만으로:** 사용자가 불확실성을 전제로 LLM을 필수로 정했으므로 쓰지 않는다. 다만 주식 수 구간 계산은 코드로 한다.
- **근거까지 Agent로 넘기기:** 사용자 결정으로 넘기지 않는다. Agent는 실행할 값만 받고, 검토는 Research에서 한다.

## Consequences

- SIW Research가 선정·분류·전략의 근거와 검토 기록을 모두 가진다. SIW Agent는 실행 값만 받는다.
- LLM 판단이 두 번(분류, 외부 감사) 들어간다. 각 판단의 모델·프롬프트 버전, 근거, 불확실성을 남겨야 사후에 검증할 수 있다.
- 유료 공매도 API와 실시간 자료는 비용·약관 확인이 먼저다.

## Revisit when

- 피보나치 논의가 끝났을 때.
- 모델 배정 회신을 받았을 때.
- 실시간 수급의 정의가 자료 확인으로 정해졌을 때.
