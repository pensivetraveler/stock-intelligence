## Context

- **사용자 요구(2026-11-23):** 원펀치매매 2권 카드(`da4ba5c5…`, 3판)에서 세 진입 방식을 각각 전략 초안으로 만든다.
  - 원펀치 0.75 단일, 투펀치 0.5·0.75 각 50%, 0.875 단일(카드 모호점 답 2·5).
- **이전 초안(`7701a747`):** 23개 항목 중 21개가 "못 옮김"이었다. 엔진에 다음이 없어서다.
  - 과거 특정 봉(기준봉)을 기억하는 상태
  - 기준봉 저점과 2차 상승 고점 사이의 사등분선(피보나치) 가격
  - 분할 진입, 분할 청산, 첫 청산 뒤 본전 손절
  - 거래대금 값
- **카드에서 읽은 기법(답 포함):**
  - 기준봉: 등락률 15% 이상·거래대금 300억 이상 장대양봉(답 1·4).
  - 조정 뒤 기준봉 고점을 몸통으로(종가로) 다시 넘는 2차 상승 봉. 그 거래대금이 1차 상승보다 많다(조건 0·4).
  - 선은 기준봉 저점(1)에서 2차 상승 고점(0)까지. 비율 r의 가격 = 고점 − r × (고점 − 저점).
  - 진입: 원펀치 0.75 / 투펀치 0.5·0.75 / 0.875.
  - 매도: 0.5만 체결 → 0 라인, 0.75까지 체결(또는 0.75 원펀치) → 0.25 라인(답 6). 0.875 매매는 0.625에서 50%, 0.25에서 나머지, 첫 매도 뒤 남은 물량은 본전에서 정리(답 7, 조건 15~18).
  - 손절: 기준봉 저점(선의 1)이 깨지면.
- **이미 되는 것:** 전일 대비 %는 `roc`(길이 1)로 쓸 수 있다. 스크립트 변환(`script_rules`)이 아직 이 꼴을 옮기지 않을 뿐이다.
- **대시보드 254**(피보나치 비율이 "저가 ≥ 0.5" 같은 가격 상수로 옮겨지던 문제)는 PR #216에서 고쳐 닫혔다. 지금은 `other` 칸이면 스크립트가 옮기지 않고 모델이 글로 읽는다.

## Decision (제안)

### 1. 전략 정의: `setup` 필드

규칙 전략에 선택 필드 `setup`을 더한다. 있으면 `entry`·`exit`·`entry_order`·`exit_order`·`stop_loss_pct`·`take_profit_pct`·`stop_loss_atr`·`trailing_stop`은 쓰지 않는다(함께 오면 거절). `sizing`·`max_positions`는 그대로 쓴다. 없으면 지금과 같아 기존 전략의 지문은 바뀌지 않는다.

```json
{
  "type": "rules",
  "setup": {
    "kind": "base_fib",
    "base": {
      "all": [
        {
          "op": "gte",
          "left": { "indicator": "roc", "params": { "length": 1 } },
          "right": { "value": "15" }
        },
        {
          "op": "gte",
          "left": { "indicator": "tv" },
          "right": { "value": "30000000000" }
        }
      ]
    },
    "breakout": {
      "op": "gt",
      "left": { "indicator": "tv" },
      "right": { "base": "value" }
    },
    "breakout_within": 20,
    "entry_within": 20,
    "legs": [
      {
        "level": "0.5",
        "size_pct": "50",
        "targets": [{ "level": "0", "sell_pct": "100" }]
      },
      {
        "level": "0.75",
        "size_pct": "50",
        "targets": [{ "level": "0.25", "sell_pct": "100" }]
      }
    ],
    "stop_level": "1",
    "breakeven_after_target": false
  },
  "sizing": { "mode": "percent_equity", "value": "10" }
}
```

- `base`: 기준봉 조건. 확정 봉마다 그 봉에서 평가한다.
- `breakout`: 2차 상승 봉의 추가 조건(없으면 null). "종가 > 기준봉 고가"는 항상 들어간다. 여기서만 `{"base": "open"|"high"|"low"|"close"|"volume"|"value"}` 피연산자로 기준봉 값을 쓸 수 있다.
- `breakout_within`·`entry_within`: 기준봉 뒤 돌파를 기다릴 봉 수, 돌파 뒤 첫 체결을 기다릴 봉 수(1~500).
- `legs`: 분할 진입 1~4개. `level`은 선의 비율(0~1), `size_pct`는 `sizing` 금액 중 그 다리의 몫(합 100). `targets`는 그 다리가 "가장 깊이 체결된 다리"일 때 쓰는 매도 사다리다. `sell_pct`는 그 목표에 닿을 때 들고 있는 수량의 몫이다(마지막은 100).
- `stop_level`: 손절선의 비율(보통 1 = 기준봉 저점).
- `breakeven_after_target`: 첫 목표 체결 뒤 손절을 평균 매수가로 올린다.

### 1-1. 비중

- `sizing`의 금액·수량을 다리마다 `size_pct`로 나눈다. 다리의 지정가를 걸 때(봉마다) 그때의 자산으로 계산한다. `fixed_shares`는 내림한다.
- **새 방식 `risk_pct`(셋업 전략에서만):** 다리 수량 = 자산 × `value`% × `size_pct`/100 ÷ (다리 가격 − 손절선). 카드의 "1회 매수 후 바로 손절 시 계좌 손실 −1%"를 옮긴다. 갭으로 손절선 아래에서 체결되면 손실은 더 커진다. 현금이 모자라면 살 수 있는 만큼 줄이고 `reduced_to_available_cash`로 남긴다.

### 2. 새 지표 `tv`(거래대금 근사)

- 값 = 종가 × 거래량. 실제 거래대금(체결마다 가격 × 수량의 합)과 다르다. 그래서 초안에서 이 지표를 쓰면 "근거에 없는 읽기"로 사용자 확인(체크)을 받는다.
- 금액 단위는 그 종목의 통화다. 카드의 "300억"은 원화 기준이라 미국 주식에는 그대로 맞지 않는다. 초안은 카드 숫자를 그대로 쓰고, 바꾸는 것은 사용자가 정한다.

### 3. 상태와 시점(미래 데이터 없음)

종목마다 상태 하나를 둔다: 대기 → 기준봉 → 무장 → 보유 → 대기.

| 상태   | 넘어가는 때(모두 확정 봉의 종가 뒤)                                                                                  |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| 대기   | 봉 i가 `base`를 만족하면 기준봉 = i                                                                                  |
| 기준봉 | 종가 > 기준봉 고가이고 `breakout` 만족 → 무장. 저가 ≤ 손절선이거나 `breakout_within` 지나면 대기. 새 기준봉이면 교체 |
| 무장   | 다리가 하나라도 체결되면 보유. 저가 ≤ 손절선이거나 `entry_within` 지나면 대기                                        |
| 보유   | 포지션이 0이 되면 대기(같은 기준봉은 다시 쓰지 않음)                                                                 |

- **2차 상승 고점:** 돌파 봉부터 직전 확정 봉까지의 최고가. 봉이 확정될 때마다 다시 계산하고, 그 값으로 다음 봉에 걸 지정가를 정한다. 첫 체결 때 그 시점의 값으로 고정한다. 체결된 봉의 고가는 넣지 않는다(체결 뒤에 나왔을 수 있다).
- **진입:** 다리마다 선 가격에 매수 지정가. 다음 봉부터 확인하고, ADR 0031처럼 뚫고 지나가야(저가 < 지정가) 체결이다. 시가가 지정가 아래로 열리면 시가에 체결한다. 고점이 바뀌면 걸어 둔 지정가도 다음 봉부터 옮긴다.
- **손절:** 저가 ≤ 손절선이면 그 가격(갭이면 시가)에 전량 매도. 손절과 목표가 한 봉에 함께 닿으면 손절로 본다(지금 규칙과 같음).
- **목표:** 고가 > 목표선이면 그 가격(갭이면 시가)에 `sell_pct`만큼 매도하고 다음 목표로 간다. 목표가 하나라도 체결되면 아직 안 걸린 진입 다리는 취소한다.
- **봉 안 순서를 모르는 경우:** 봉 안에서 체결된 다리가 있는 봉에서는 목표를 보지 않고 손절만 본다(고가가 체결 전에 나왔을 수 있다). 본전 손절은 목표가 체결된 다음 봉부터 쓴다.
- **분할 진입:** 다리 둘이 한 봉에서 함께 체결될 수 있다. 거래 기록은 한 건이고, 진입가는 평균 체결가, 수량은 합이다. 체결은 다리마다 `fills`에 따로 남는다.

### 4. 기존 경로와의 관계

- **SIW Agent·모의 실행:** `setup` 전략은 백테스트에서만 쓴다. 모의 실행 승인에서 거절한다. 실행기에 지정가 사다리·보호 주문이 없기 때문이다(ADR 0044 별도 작업).
- **Pine 템플릿:** `setup`은 템플릿에 없다. `unsupported`에 적고 Pine에서는 진입이 일어나지 않는다. TradingView 대조는 다음 작업이다.
- **데스크톱 규칙 편집기:** `setup` 전략은 폼으로 열지 않는다(지금의 "너무 깊어 폼으로 못 보임"과 같다). 저장된 정의는 바꾸지 않는다.
- **Pine → 규칙 변환(ADR 0042 대화):** 바꾸지 않는다. `setup`은 기법 카드 초안의 모델 안내에만 넣는다.

### 5. 초안에서 쓸 항목 고르기

- 초안 요청에 `items`(카드 항목 번호 목록)와 `label`(예: "원펀치 0.75")을 더한다. 카드 판은 그대로다.
- 고르지 않은 항목은 모델에 보내지 않고 `excluded`("이 초안에서 쓰지 않음, 사용자 선택")로 남긴다. 못 옮김 수에 넣지 않는다.
- 같은 카드에서 방식별 초안 3개를 만든다. 저장 조건(못 옮김 체크, 근거 없는 읽기 체크, 카드 판 일치)은 지금과 같다.
- **스크립트 변환 보강:** "종가가 전일 종가 대비 N% 이상" 꼴(오른쪽 `percent`·`previous_close`)을 `roc`(길이 1) ≥ N으로 옮긴다.

## 고려한 대안

- **Python 전략으로 초안을 만든다:** 지금도 표현은 된다. 하지만 ADR 0056은 규칙 빌더 먼저이고, 코드 실행은 검토·승인 단계가 따로 필요하다.
- **ADR 0038의 `levels`를 먼저 구현한다:** 절대 가격·지표 가격의 지정가는 되지만, 기준봉 상태와 다리별 매도 사다리가 없다. 이 셋업이 0038 L1의 백테스트 체결을 일부 앞당긴 셈이다.
- **2차 상승 고점을 "N봉 동안 새 고가 없음"으로 확정한 뒤 선을 긋는다:** 더 보수적이지만 N이라는 근거 없는 숫자가 생긴다. 2026-11-23 사용자가 "첫 체결 때 고정"을 골랐다.

## 다시 볼 조건

- 카드 셋 이상이 같은 꼴(기준봉·되돌림 비율)을 쓰면 `kind`를 늘리지 말고 일반 상태 규칙을 검토한다.
- 첫 백테스트에서 지정가가 매일 옮겨져 체결이 책과 크게 다르면 고점 확정 방식을 다시 정한다.
- SIW Agent가 지정가 사다리를 지원하면 모의 실행 거절을 푼다.
